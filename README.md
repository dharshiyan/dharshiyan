## 🚀 Featured Projects

### 1. PersonalAssistant
**Python | RAG | Scikit-learn | SQLite | FastAPI**

A modular personal assistant focused on local knowledge retrieval, conversation management and task handling.

- Implemented hybrid retrieval using TF-IDF, BM25 and Reciprocal Rank Fusion (RRF).
- Built document processing, relevance ranking and context selection.
- Developed confidence scoring, source attribution and reference resolution.
- Implemented conversation persistence and task management using SQLite.
- Validated core functionality with 288 passing unit tests.

### 2. InboxSentinel – Spam & Phishing Detection
**Python | NLP | Scikit-learn | BERT | Streamlit**

A multiclass email classification system that identifies legitimate, spam and phishing messages.

- Processed a dataset containing 515K+ records.
- Achieved 95.8% accuracy using TF-IDF and Logistic Regression.
- Experimented with BERT, achieving approximately 97.97% validation accuracy and F1-score.
- Developed an interactive Streamlit prediction interface.

### 3. RiskGuard-AI – Intelligent Multi-Camera Surveillance 🚧
**Python | PyTorch | YOLOv8 | ResNet50 | DeepSORT | OpenCV**

Developing a risk-aware surveillance system for security monitoring.

- Focuses on suspicious behaviour detection and selective person tracking.
- Integrates object detection and person re-identification.
- Implements risk scoring and explainable security alerts.
- Designed for multi-camera tracking and security event monitoring.

### 4. NovaPixel – AI Image Super-Resolution
**Python | PyTorch | GAN | OpenCV**

Developed a GAN-based portrait enhancement model without relying on pretrained models.

- Trained using 1,023 portrait images.
- Designed a generator with approximately 1.55M parameters.
- Achieved PSNR of 28.58 and SSIM of 0.8450 after 10 epochs.
- Focused on enhancing image resolution up to 4×.

### 5. Dog vs Cat Image Classification
**Python | TensorFlow | Keras | CNN**

- Developed a CNN model for binary image classification.
- Applied image preprocessing and data augmentation.
- Trained and evaluated the model using TensorFlow and Keras.
